# 3Sum

**Topic:** Two Pointers · **Difficulty:** Medium · **Status:** Solved independently (no hints, ~20 min)

---

## Quick Revision

| | |
|---|---|
| **Pattern** | Sort, fix `i`, then two pointers `j = i+1`, `k = n-1` looking for `nums[j] + nums[k] == -nums[i]` |
| **Core** | Sum too small → `j++`; too big → `k--`; equal → add, skip equal `j`s and `k`s, then `j++`, `k--` |
| **Key insight** | Sorting makes each pointer move safe, and puts duplicates side by side so skipping them removes duplicate triplets with no set |
| **Complexity** | O(n²) time (sort O(n log n) is added, not multiplied); O(1) extra plus O(log n) for `Arrays.sort`, output not counted |
| **Traps** | Skip duplicates for all three of `i`, `j`, `k`; `[0,0,0,0]` must give one `[0,0,0]`; sorting changes the caller's array |

**Early exit:** once `nums[i] > 0`, no triplet can sum to 0, so stop.
**Follow-up:** 4Sum fixes two indices then two pointers, O(n³); add the four values as `long` to avoid overflow.

---

## Code

```java
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;                          // only positives left
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // same first number
        int j = i + 1, k = nums.length - 1, target = -nums[i];
        while (j < k) {
            int sum = nums[j] + nums[k];
            if (sum < target) j++;
            else if (sum > target) k--;
            else {
                res.add(List.of(nums[i], nums[j], nums[k]));
                while (j < k && nums[j] == nums[j + 1]) j++;
                while (j < k && nums[k] == nums[k - 1]) k--;
                j++;
                k--;
            }
        }
    }
    return res;
}
```
